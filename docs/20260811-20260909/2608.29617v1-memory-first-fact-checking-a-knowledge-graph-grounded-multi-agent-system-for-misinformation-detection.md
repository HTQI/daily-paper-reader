## 摘要
本文介绍了一种混合事实核查框架，该框架将基于知识图谱的语义记忆与对抗性多智能体推理相结合，用于可解释的错误信息检测。所提出的系统遵循记忆优先、网页回退的架构，其中输入的主张首先通过基于Sentence-BERT的语义检索和自然语言推理，对照双索引知识图谱进行评估。当从图谱中检索到的证据不足以支持可靠决策时，该框架从可信网络来源收集信息，并使用由支持、矛盾和判定智能体组成的对抗性法庭进行评估。一种图感知的置信度机制结合了语义相似性、NLI置信度和结构图证据，以确定内部知识是否足够，从而减少不必要的网络检索。验证后，经过验证的信息被转换为结构化三元组并入知识图谱，支持系统语义记忆的增量扩展。在精选的COVID-19错误信息基准上的实验评估表明，所提出的框架在已解决的主张上达到了97.4%的准确率和92.6%的宏平均F1分数，优于Llama~3.3~70B基线，后者获得了87.7%的准确率和86.3%的宏平均F1分数。

## Abstract
This paper introduces a hybrid fact-checking framework that integrates Knowledge Graph-based semantic memory with adversarial multi-agent reasoning for explainable misinformation detection. The proposed system follows a memory-first, web-fallback architecture, in which input claims are initially evaluated against a dual-index Knowledge Graph through Sentence-BERT-based semantic retrieval and Natural Language Inference. When the evidence retrieved from the graph is insufficient to support a reliable decision, the framework collects information from trusted web sources and assesses it using an adversarial tribunal composed of support, contradiction, and judging agents. A graph-aware confidence mechanism combines semantic similarity, NLI confidence, and structural graph evidence to determine whether internal knowledge is sufficient, thereby reducing unnecessary web retrieval. Following verification, validated information is transformed into structured triples and incorporated into the Knowledge Graph, supporting the incremental expansion of the system's semantic memory. Experimental evaluation on a curated COVID-19 misinformation benchmark demonstrates that the proposed framework achieves an accuracy of 97.4\% and a macro-averaged F1-score of 92.6% on resolved claims, outperforming a Llama~3.3~70B baseline, which obtains an accuracy of 87.7% and a macro-averaged F1-score of 86.3%.

## 2. 论文提出的方法论

### 2.1 核心思想

系统遵循“**记忆优先、网页回退**”的架构逻辑，将事实核查视为两层递进过程：

1. **内部记忆层（KG）优先决策**——先对输入声明做基于知识图谱的语义检索与自然语言推理（NLI）判断；
2. **外部证据层（Web）回退补充**——仅当内部知识不足以支撑可靠判定时，才激活信任网络检索与对抗性多智能体审议。

验证完成后，结果以**三元组形式回写图数据库（Neo4j）**，形成“验证即学习”的正反馈闭环。整个系统由 **CrewAI** 协调多智能体流程，嵌入生成与 NLI 推理由独立的 FastAPI 服务执行；事实判定与用户解释生成相分离——下游解释组件只能总结证据，不能修改既定判定。

### 2.2 关键技术细节

#### （1）双索引知识图谱（Dual-Index KG）

- 两个互补向量索引：
  - **MACRO 索引**：完整声明节点（Claim），保留上下文表述；
  - **MICRO 索引**：原子事实节点（VerifiedFact / ClaimedFact），以 Subject-Predicate-Object 三元组存储。
- 两种索引均使用 `all-mpnet-base-v2` 生成 **768 维向量**，采用余弦相似度检索。
- 候选节点需满足相似度门槛：S(c, n) ≥ 0.75，否则直接转入网络验证。
- 若双索引均返回合格候选，由**确定性仲裁规则**选择最优表达层级：
  - 短声明（≤6 词）偏好 MICRO（两相似度差 ≤0.03 时）；
  - 长声明一般倾向 MACRO（上下文更完整）；
  - 若 MICRO 相似度超过 MACRO 达 0.05，则 MICRO 覆盖此偏好。

#### （2）NLI 与图感知决策层

- 使用 `facebook/bart-large-mnli` 模型，以图节点存储语句为前件（premise）、输入声明为假说（hypothesis），推断 ENTAILMENT / CONTRADICTION / NEUTRAL 概率。
- **表 I 的关键规则**：
  - 蕴含（Entailment）+ 图中存储为 TRUE → 声明为 TRUE；
  - 蕴含 + 存储为 FALSE → 声明为 FALSE（输入复述了已被识别的错误信息）；
  - 矛盾（Contradiction）反转存储结论，但存在**安全限制**（如矛盾仅当图谱邻域存在修正证据时才接受为 TRUE）；
  - 中性（Neutral）为“置信度门控”结果。
- **图感知置信度公式**：
  - C = 0.60·S + 0.30·N + 0.10·G
  - S：语义相似度；N = max(P(ENTAILMENT), P(CONTRADICTION))；G：邻域结构化证据支撑。
  - C 作为路由信号，而非校准概率，判断是否转向网络验证。
- **安全护栏**：
  - **路径特异性相似度检查**（MACRO/MICRO 分开执行）；
  - **数值守卫**（numeric guard）：检测措辞结构相似但数值、时间、地域等不同的对；
  - **高中性守卫**（high-neutrality guard）：NLI 表现出强逻辑不确定时拒绝图内判定。
  - 任一步触发安全护栏 → 内部判定视为未解决，转发至网络验证。

#### （3）网络证据流水线

- 由 LLM 辅助的**查询优化器**改写声明为紧凑搜索查询，保留实体、关系、语义极性和数值信息。
- 通过 DuckDuckGo 检索至多 40 条候选结果。
- 依据**白名单**（事实核查组织、公共卫生机构、科学医学来源、正规新闻通讯社）筛选 URL。
- 至多抓取 5 个不同信任域名的页面，以 100 词为跨度（25 词重叠）切分段落。
- 段落经 `all-mpnet-base-v2` 排序；含显式核查/驳斥语言的段落获得小幅相关度加分。
- 经**同域多样性去重**（每域至多 2 段）后生成至多 6 段证据包，附相关度与来源 URL。
- 最高段相似度 < 0.40 → 证据不足，返回 NEUTRAL，不激活法庭审议。

#### （4）对抗性多智能体审议法庭（Adversarial Tribunal）

- 三分角色（均为 Llama-3.3-70B-Instruct-Turbo，temperature=0.0）：
  - **Support Analyst**（支持分析）：从证据中找支撑点；
  - **Contradiction Analyst**（矛盾分析）：寻找直接矛盾、条件限定、缺失背景、非概括性推广问题；
  - **Judge**（裁判）：结合原始声明、证据包与双方分析，输出 {TRUE, FALSE, NEUTRAL} + 解释、置信度、来源、纠错断言。
- 两位分析师被约束在检索证据范围内、必须关联来源 URL；法官评估证据质量、具体性和覆盖度，而非分析师论述的修辞强度。
- 仅当技术执行失败（如 API 错误）时才会走单次网络核查，而非常规路径；合法的 NEUTRAL 弃权不被覆盖。

#### （5）知识持久化（记忆增量扩展）

- 最终判定 TRUE：将验证声明 + 支持事实写入图谱。
- 判定 FALSE：可存储原始虚假声明 + 经更正的验证声明，以 `CORRECTED_BY` 关系连接。
- NEUTRAL 不持久化。
- 三元组入库前会过滤含模糊实体、异常谓词、占位值或话语层面表达的劣质三元组。
- 通过归一化精确匹配、预定义别名、模糊词法匹配做实体消解。
- 每条存储保留溯源信息（源 URL、类型、验证时间戳）。

## 7. 优点

1. **架构设计创新性强**：将“记忆优先、网络回退”这一认知原则系统化落地为工程架构，核心问题意识清晰——不是“尽可能多检索”，而是“尽可能少但必要地检索”；
2. **可解释性贯穿始终**：判定由确定性 KG 层或证据型法庭做出，分析必须附来源 URL，最终解释仅汇总证据不带额外生成自由度，防止解释层篡改判定——公开透明的审计链路；
3. **“验证即学习”的正反馈循环**：将验证结果回写 KG 形成持久性语义记忆，使系统越用越强，知识存储效率随时间递增；
4. **安全护栏机制细腻**：数值守卫、高中性守卫、路径分离等设计降低了 NLI 在数值/否定/近似语义上的天然脆弱性；
5. **精度高且可控性好**：97.4% 准确率与 99.5% 的法庭路径准确率令人印象深刻，且 NEUTRAL 作为有原则的弃权是处理不确定性的严谨做法；
6. **基准数据未见泄漏**：评估声明与数据构建隔离，避免了最根本的评估偏差问题。

## 8. 不足与局限

1. **缺乏受控消融实验**：论文自己也承认，KG/tribunal/恢复路径处理的是不同子集，无法准确量化各组件在性能中的单独贡献。置信度权重（0.6/0.3/0.1）、相似度阈值（0.75/0.40）等的设定均缺乏敏感性分析。
2. **领域泛化性未验证**：仅在 COVID-19 相关数据集上做评测，跨领域（政治、金融、科技等）的错误信息形态差异很大，结论能否推广尚属未知。
3. **时间敏感性与信息过时风险**：错误分析中明确提到网络证据可能反映“过时的科学指导”，且系统没有显式的时间过滤机制——这对于需要跟踪科学认知演进的健康类事实核查尤为关键。
4. **基线对比不完全公平**：
   - 基线的 100% 覆盖率并不一定代表优势——无足够证据时的“强行判定”可能是错误来源，但论文并未对“不同覆盖率条件下如何选择指标”做系统性讨论；
   - 基线是无检索、无工具的裸 LLM，未与具备 RAG/网络搜索/结构化推理的同等规模基线系统（如带搜索的 Agent、FactKG 等）作同类对比；
   - 报告的方法与基线在推理成本/延迟上的差额未给出。
5. **“90.7% 覆盖率下 97.4% 准确率”的双刃剑**：31 条 NEUTRAL 避免了错误，但真实部署场景往往不允许“弃权”，需要如何处理覆盖率与准确率之间的 Pareto 折中。
6. **工程复杂度与复现门槛**：系统依赖多个外部组件（Neo4j、CrewAI、FastAPI、Together AI API、DuckDuckGo、多份白名单），组件链较长，稳定性与可复现性可能受单一 API 故障影响。
7. **计算方法细节缺失**：图支撑分量 G 的精确计算方式、置信度阈值具体数值、NLI 模型与嵌入模型版本等细节均未给出，第三方复现存在难度。
8. **受试规模有限**：333 条精选测试声明的规模偏小，统计功效有限，8 条误分类的错误分析样本也很小，不适合做深层的模式推断。
