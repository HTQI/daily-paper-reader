## 摘要
现实世界中的多模态虚假信息通常涉及混合伪造来源，需要针对样本的检测策略。现有的工具增强方法依赖预定义工作流或推理时规划，限制了适应性或增加了推理成本。为解决这一问题，我们引入 MM-VeriAgent，它学习使用工具来验证混合来源的多模态虚假信息。我们首先构建 MM-VeriTools，一个面向虚假信息检测智能体的专用工具包。通过在混合来源检测所需的子任务上对多种候选模型和方法进行基准测试，我们为文本、视觉和跨模态伪造分析选择最强的方法，并将其封装为具有统一接口的可调用工具。在此工具包之上，我们使用强化学习训练 LVLM 智能体，以教会它如何使用这些工具来更好地解决混合来源检测。由于许多工具是专用模型，其在每次 rollout 时的在线执行严重限制了强化学习效率，我们进一步引入 Tool-Execution Cache，它预先执行候选工具调用，并在训练期间复用其缓存输出。这在保留多步 rollout 的同时减少了在线工具执行，大幅提高了训练效率。在 MMFakeBench 上的实验表明，在没有推理时显式工具搜索的情况下，相比基础模型取得了显著的准确率提升。消融和效率分析进一步验证了所学到的工具使用策略，并表明 Tool-Execution Cache 减少了训练期间的在线工具执行。

## Abstract
Real-world multimodal misinformation often involves mixed forgery sources, requiring sample-specific detection strategies. Existing tool-augmented methods rely on predefined workflows or inference-time planning, limiting adaptability or increasing inference cost. To address this issue, we introduce \textbf{MM-VeriAgent}, which learns to verify mixed-source multimodal misinformation with tools. We first build \textbf{MM-VeriTools}, a specialized toolkit for misinformation detection agents. By benchmarking various candidate models and methods on the sub-tasks required by mixed-source detection, we select the strongest for textual, visual, and cross-modal forgery analysis and encapsulate them as callable tools with a unified interface. On top of this toolkit, we train the LVLM agent with reinforcement learning to teach it how to use these tools to better solve mixed-source detection. Since many of the tools are specialized models whose online execution at every rollout severely limits RL efficiency, we further introduce \textbf{Tool-Execution Cache}, which pre-executes candidate tool calls and reuses their cached outputs during training. This preserves multi-step rollouts while reducing online tool execution, largely improving the training efficiency.Experiments on MMFakeBench demonstrate substantial accuracy gains over the base model without explicit tool search at inference time. Ablation and efficiency analyses further validate the learned tool-use policy and show that Tool-Execution Cache reduces online tool executions during training.

## 1. 核心问题与整体含义

- **研究背景**：现实世界中的多模态虚假信息很少只来自单一伪造来源。MMFakeBench 将其形式化为三类失真：文本真实性失真（TVD）、视觉真实性失真（VVD）、跨模态一致性失真（CCD），且测试时来源组成未知，不同来源需要不同的验证机制（事实核查、视觉取证、跨模态一致性推理）。
- **核心问题**：固定的检测流水线无法匹配混合来源输入，有效检测需要针对每个样本决定"收集哪些证据、何时停止"。
- **现有方法的局限**：
  - 预定义工作流类方法（MMD-Agent、LRQ-FACT、DEFAME 等）对所有输入执行基本相同的工具序列，无法适应样本级伪造来源；
  - 测试时规划/搜索类方法（T²Agent、DEFAME）适应性更好，但每个输入都需额外计算来规划调用或评估候选轨迹，推理成本高。
- **整体含义**：论文主张将多模态虚假信息检测从"仅预测标签"推进到"可审计、证据落地的验证"，兼顾样本级适应性与推理效率。据作者所述，MM-VeriAgent 是**首个真正用强化学习训练**的混合来源多模态虚假信息检测模型，而此前智能体仅做直接推理。

## 2. 方法论

### 2.1 核心思想
构建专用工具包 → 用 RL 训练 LVLM 智能体学习"调用哪个工具、何时停止" → 用离线工具执行缓存加速 RL 训练，使推理时无需显式规划或搜索。

### 2.2 关键技术细节

**（1）MM-VeriTools 工具包构建（两步）**
- **收集与分组**：按 TVD、VVD、CCD 三个子任务收集候选专用模型与 API，统一封装为可调用接口。所有工具从被查询样本取固定参数，因此工具调用只需指定工具名。
- **基准测试与剪枝**：为每个子任务从 MMFakeBench 训练集构建平衡基准（300 个目标来源样本 + 300 个 Real 样本，与测试集不重叠）。比较三类候选：Base（GPT-5-mini 无工具）、Auxiliary（作为唯一工具附于 base）、Direct（直接输出子任务答案）。**仅保留优于 base 模型（0.63/0.66/0.53）的候选**。
- **最终工具集**：共 9 个工具——4 个文本类（GLiNER-medium 实体抽取 0.71、Wikipedia 检索 0.71、Google 检索 0.75、Qwen3-30B 文本事实核查 0.69），4 个视觉类（DFFreq 0.94、DDA 0.91、MVSS-Net 0.86、Qwen3-30B 篡改描述 0.80），1 个跨模态类（CapRL 图像描述 0.92）。被淘汰的包括 Faking Fake News、UnivFD、HAMMER、FKA-Owl 等。

**（2）任务定义与多轮工具使用**
- 输入为图文帖 x = (I, T)，需预测二值真实性标签 y、细粒度来源标签 z ∈ {Real, TVD, VVD, CCD}、支撑证据 Ê 与自然语言推理。
- 轨迹形式：τ = (a₀, o₀, a₁, o₁, …, a_{K−1}, o_{K−1}, a_K)，其中 a_k 为工具调用动作（以工具专属停止 token 结尾）或终止动作，o_k 为工具返回的观测。
- 轨迹分布按策略自身生成分解：P_θ(τ|x) = ∏_{k=0}^{K} π_θ(a_k | x, a_{<k}, o_{<k})，观测由环境注入而非策略生成——这一性质被同时用于缓存训练与损失掩码。

**（3）强化学习训练**
- **奖励设计**（四项组合）：
  - R_veracity = I[ŷ = y]，R_source = I[ẑ = z]（指示函数）；
  - R_evi = |Ê ∩ E*| / |Ê ∪ E*|（证据重叠，采用集合 F1 形式）；
  - R_fmt = I[输出可解析且标签合法]；
  - 最终 R = λ_y·R_veracity + λ_z·R_source + λ_e·R_source·R_evi + λ_f·R_fmt，**证据项由 R_source 门控**（仅在来源归属正确时才奖励证据重叠）。实际权重 λ_y = λ_f = 0.3，λ_z = λ_e = 2.0，偏向细粒度来源归属。
- **冷启动 SFT**：最小化负对数似然 L_SFT(θ) = −E[log π_θ(τ*|x)]，赋予基本验证能力与工具调用格式。
- **GRPO 训练**：对每个样本采样 G 条轨迹，计算组归一化优势 A_i = (R_i − mean{R_j}) / std{R_j}；采用 token 级裁剪目标 L_clip，重要度比 r_{i,t}(θ) = π_θ(τ_{i,t}|τ_{i,<t}) / π_θold(τ_{i,t}|τ_{i,<t})；总目标 J_GRPO = E[L_clip − β·D_KL(π_θ‖π_ref)]。
- **掩码处理**：观测 token 相对于 π_θ 是 off-policy，被排除在损失与 KL 计算之外；实现上缓存观测单独 tokenize 后与动作段拼接，保证动作 token 与策略生成完全一致。

**（4）Tool-Execution Cache**
- **动机**：工具包中许多是慢速专用模型，RL 阶段跨 rollout 与策略更新反复执行，成为训练主瓶颈并引入响应方差。
- **离线构建**：训练前，教师智能体（GPT-5-mini，温度 1.0）对每个训练样本执行 5 次 rollout，在线执行全部工具调用并记录返回上下文；异构输出（检索段落、取证分数、描述）统一转为文本条目 e_j = (id_j, title, tool_name_j, content_j)。
- **缓存式 rollout**：策略调用工具时，环境按样本与工具名匹配缓存并返回内容，o_k = C_x(tool(a_k))；未命中则回退到在线执行。
- **有效性依据**：工具集内每个工具都是**无状态且参数固定**的，输出仅取决于工具与被查询图文对，因此样本级匹配即可返回忠实于真实执行的结果（区别于终端等有状态环境，后者需整个调用历史匹配）。

## 6. 主要结论与发现

- **性能提升显著**：MM-VeriAgent 将 Qwen2.5-VL-7B 的多分类准确率从 **34.3% 提升至 70.4%**，二分类 F1 达 **85.1%**（所有方法中最佳），与更大规模闭源模型持平（Gemini-2.5-Pro 多分类 69.8%，GPT-5.5 为 71.8%），且推理时**无需任何显式工具搜索或规划**。
- **工具本身不等于有效**：未训练的 Qwen2.5-VL-7B 使用紧凑 MMD-Agent 工具集可从 34.3% 升至 41.3%，但使用更丰富的 MM-VeriTools 反而**降至 26.0%**——更丰富的动作空间会淹没未训练策略。GPT-5-mini 同样在 MMD-Agent 工具集（65.2%）上优于 MM-VeriTools（57.1%）。
- **收益来自 RL 而非数据**：SFT(8k) 已达 59.6%，再加 2k 监督数据（SFT-10k）几乎无变化（59.8%），而用 GRPO 优化同 2k 样本达到 70.4%——增益源于基于交互的优化。
- **学生超越教师**：GPT-5-mini 生成 SFT 数据与缓存，但在同一工具集下仅 57.1%，说明智能体学到的是真正的工具使用策略而非简单蒸馏。
- **跨模态工具最关键**：移除 CCD 工具使多分类 ACC 从 70.4% 降至 58.3%、macro-F1 从 71.5% 降至 58.6%，降幅最大——跨模态失真无法从任一单模态单独识别。
- **证据奖励有效**：移除证据奖励使多分类 ACC 降至 66.1%、macro-F1 降至 66.7%，说明仅优化预测正确性不足以支撑细粒度归属。
- **缓存效率**：5 次教师 rollout 后缓存命中率达 100%，单样本 rollout 时间从 40.3 秒降至 6.5 秒（6.2× 加速），训练无需在线工具执行。

## 7. 优点

- **问题定位准确**：清晰指出现有工具增强方法在"样本级适应性"与"推理效率"之间的两难，并以学习式策略同时解决。
- **工具包构建有方法论**：不是随意堆叠工具，而是通过 base / auxiliary / direct 三类候选的定量基准测试与"边际贡献"剪枝原则筛选，保证每个工具都有独立价值。
- **奖励设计精细**：证据奖励采用集合重叠（F1 形式）并由来源正确性门控，避免了"来源对了但证据无关"被错误奖励；权重分配体现细粒度归属为核心目标。
- **训练与推理解耦的工程巧思**：Tool-Execution Cache 利用"工具无状态、参数固定"的性质，在保留真实多步交互的同时把昂贵工具执行移到离线阶段，命中率可达 100%。
- **损失掩码处理规范**：明确区分策略生成的 action token 与环境注入的 observation token，仅在 action token 上计算损失与 KL，符合 agentic RL 的正确做法。
- **对照实验设计严谨**：SFT-10k 对照有效排除数据量混淆；"学生超越教师"的发现增强了结论可信度。
- **可审计性**：输出包含来源归属与引用证据，使验证过程可追溯，而非仅输出标签。

## 8. 不足与局限

- **工具质量依赖**：智能体继承工具的质量上限；若检索失败或取证检测器校准失当，智能体可能累积误导性证据并放大错误。
- **缓存适用条件受限**：Tool-Execution Cache 依赖无状态、输入由样本决定的工具；对自由参数或输出随时间变化的工具，需要更细粒度的匹配与缓存版本管理。
- **评测覆盖窄**：仅限 MMFakeBench（当前混合来源验证的主要基准），对未见伪造生成器、新闻领域、以及三类来源之外的失真类型的泛化性尚未验证。
- **扩展成本高**：引入新的失真类型需要重新基准测试候选工具并重新训练策略，缺乏即插即用的可扩展性。
- **推理成本仍高于纯分类**：基于工具的验证比答案式分类昂贵，论文建议工具预算应随风险缩放，但未给出具体策略。
- **算力与效率报告

不全**：论文未报告总 GPU 小时数、训练时长、SFT/RL 各自步数与 wall-clock 时间，也未给出推理延迟/吞吐指标，仅提供缓存前后的单样本 rollout 时间对比；这使读者难以评估方法在真实部署中的成本可行性，也难以复现训练预算。
- **策略可靠性缺乏鲁棒性分析**：论文未报告多次随机种子运行的方差、置信区间或统计显著性检验，单点结果（如 70.4%）的稳定性无法确认。

## 9. 总结性评价与启示

- **方法层面的核心贡献**：论文把"多模态虚假信息检测"重新表述为一个**样本级证据采集决策问题**，并用 RL 让策略内化"选工具—读观测—判停止"的流程。其关键洞察在于：适应性不必来自推理时的显式规划或搜索，而可以**预先蒸馏进策略参数**，从而在推理时以单次前向加少量工具调用完成验证。这一"训练时昂贵、推理时廉价"的取舍，是对 T²Agent 等测试时搜索范式的直接替代方案。
- **工程层面的关键设计**：Tool-Execution Cache 与损失掩码共同构成了 agentic RL 在多工具环境下的可训练性方案。前者利用工具的**无状态性与样本级参数固定**这一结构性假设，把环境交互从训练循环中剥离；后者保证梯度只作用于策略可控的 action token，避免对 off-policy 观测的误导性优化。二者结合使 GRPO 在长轨迹、异构工具场景下仍然稳定可训。
- **实证层面的主要发现**：① 工具数量与能力并非单调增益，未训练策略在更丰富的动作空间中反而退化（41.3% → 26.0%），说明**动作空间复杂度必须与策略能力匹配**；② 增益来源被严格归因于 RL 而非监督数据量（SFT-10k 59.8% vs. GRPO 70.4%）；③ 跨模态工具贡献最大，印证 CCD 是混合来源验证中信息量最高、也最不可替代的维度；④ 证据奖励对细粒度归属有实质作用，仅优化标签正确性不足以保证可审计性。
- **方法论上的可迁移启示**：
  - "**先基准测试、后剪枝**"的工具筛选流程可推广到其他工具增强智能体任务，其本质是以 base 模型为参照，只保留具备边际贡献的候选，避免工具集膨胀。
  - "**证据奖励由主任务正确性门控**"是一种通用的多目标奖励构造技巧，可用于任何需要"答案 + 依据"双重正确的任务。
  - "**离线缓存 + 在线回退**"的混合执行模式为慢速外部依赖（检索、专用模型、API）下的 RL 训练提供了低成本路径。
- **对后续研究的指向**：论文的局限本身勾勒出若干可延展方向——跨数据集与跨生成器的泛化评测、工具集的即插即用扩展机制（如按需重新基准测试而非整体重训）、风险自适应工具预算策略、以及策略失败模式的可解释诊断。若能在这些方向补齐，方法有望从"在单一基准上超越闭源大模型"走向"在开放环境中可持续演进的可审计验证系统"。
