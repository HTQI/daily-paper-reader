## 摘要
错误的数字比没有答案更糟糕。在事实关键领域——受众指标、媒体日程与版权；医疗中的剂量与化验值；金融和法律中的数字与引用——一个自信但捏造的值比诚实地承认不确定性更具破坏性。然而，这是我们在小型本地语言模型上观察到的主要失败模式：即使上下文中存在正确证据，模型也会捏造看似合理的数字和时间戳。近期的研究揭示了这一机制的实际局限：在70亿参数以下，检索增强生成（RAG）的瓶颈并非检索质量，而是上下文利用率。我们提出了Noesis，即Noesis架构的确定性优先查询平面，它在生成之前做出所有确定性判断。其机制源自摄取架构（另有一项专利申请）：（a）生产者侧事实层，逐字渲染预计算的指标事实，无需排序；（b）位置寻址与确定性跨源对齐，在查询时间之前解析，LLM成本为零；（c）来源范围作为归因约束，采用多层命名引用路由；以及（d）双层上下文，带模型触发的逐字补全。在四项消融实验中，一个2B模型在事实完整性方面与35B模型达到同等水平（所有运行中数值准确；在缺失实体陷阱上零捏造数字）；结构化检索在2B下比平面RAG高出11.4个百分点；仅骨架上下文在提示词缩小20-30%的情况下保留了定量答案；补全在约8秒内恢复逐字叙述，而对比约29秒。两个特性对受监管领域至关重要：每个查询在单次生成调用中完成，且每个报告的值通过构造可追溯到其确切来源和位置。

## Abstract
A wrong number is worse than no answer. Across factuality-critical domains -- audience metrics, scheduling and rights in media; dosages and lab values in healthcare; figures and citations in finance and legal -- a confident but fabricated value is more damaging than an honest admission of uncertainty. Yet this is the dominant failure mode we observe on small local language models: even when correct evidence is present in context, models fabricate plausible numbers and timestamps. Recent work characterizes a real limit of this regime: below 7B parameters, the bottleneck of retrieval-augmented generation (RAG) is not retrieval quality but context utilization.   We present Noesis, the deterministic-first query plane of the Noesis architecture, which makes every deterministic judgment before generation. Its mechanisms follow from the ingestion architecture (subject of a separate patent application): (a) a producer-side fact layer rendering precomputed metric facts verbatim without ranking; (b) positional addressing with deterministic cross-source alignment, resolved ahead of query time at zero LLM cost; (c) provenance scoping as an attribution constraint with multi-tier named-reference routing; and (d) two-tier context with model-triggered verbatim hydration.   Across four ablations, a 2B model reaches parity with a 35B model on factual integrity (exact values in all runs; zero confabulated numbers on absent-entity traps); structured retrieval beats flat RAG by +11.4 points at 2B; skeleton-only context preserves quantitative answers at 20-30% smaller prompts; and hydration recovers verbatim narrative in ~8s versus ~29s. Two properties matter for regulated domains: each query resolves in a single generation call, and every reported value is traceable to its exact source and position by construction.

## 1. 核心问题与研究动机

**背景问题链条：**

- **小型模型 RAG 的规模耦合困境**：已有对照研究表明，低于 7B 参数的模型使用 RAG 时，瓶颈不是检索质量而是"上下文利用率"——即使检索片段保证包含答案，小模型也往往不可靠地使用它；在标准条件下，添加检索上下文甚至可能是净负面效果。
- **关键事实查询中的"编造"（Confabulation）问题**：论文认为比检索失败更严重的生产故障是——当问题要求精确值（具体数字、时间戳、区间位置）时，模型即使看见正确证据，仍会生成语料库中不存在的"貌似合理"的数字和时间戳。错误数字比没有答案更有害（编辑决策、临床判断、财务决策上的实际危害）。
- **急切检索导致的上下文膨胀**：标准 RAG 无论问题是否需要都急切地注入 top-k 散文块，散文与少数关键确定性数值竞争注意力，在小模型最容易退化的地方膨胀 prompt。

**核心论点**：小模型答案质量对模型规模的耦合是"查询接口的伪影"，而非"模型能力的限制"。对于关键事实类查询，答案质量的首要决定因素应是**确定性基础设施**，而非模型规模。

## 2. 方法论：Noēsis 查询平面的核心机制

### 总体原则：生成前完成一切确定性判断（Deterministic-First）

Noēsis 采用**生产者/查询解耦**架构：知识库声明自己拥有什么，查询平面消费声明而不解释格式。图谱扮演"一等导航器"，回答"信息在哪"；嵌入只在该位置取内容——颠覆了向量相似度决定一切的传统 RAG 优先顺序。

### 四个核心机制

**(a) 确定性事实层（Deterministic Fact Layer）— 第 3 节**
- 指标极值（最大值、最小值及其位置）在**摄取时**由生产者计算并物化为图谱节点。
- 查询时，确定性事实**逐字渲染**到上下文的顶部专属区段，在一切散文之前。
- **无阈值水平**：事实从不被评分、排序或过滤——存在即到达模型。
- 词汇由生产者拥有：指标名称的表面变体由生产者声明的词汇表解析。

**(b) 位置寻址与确定性跨源对齐（Positional Addressing）— 第 4 节**
- 内容沿生产者声明的有序属性做**位置可寻址化**（广播的秒、剧集的场景、文档的有序章节）。
- 跨源对齐（如"X 达到峰值时发生了什么"）在**查询前**确定性解析，通过遍历预计算关系完成，零 LLM 成本。
- 机制不携带领域语义，通用适用于任何有序属性。

**(c) 来源范围限定与命名引用路由（Provenance Scoping）— 第 5 节**
- 关键区分：**范围限定归因，绝不限制数据访问**。所有来源保持可访问，只约束归因。
- 问题点名来源时，系统将该名称与 KB 清单确定性匹配，即使相似度信号弱也保证该引用到达模型。
- 跨网格（mesh）层面：命名的来源成为问题的"地址"，其他语料不得稀释上下文。
- 地址承诺的实测修正：短 token 不能独立锚定引用（防止领域缩写误路由）；相关性需跨多区域持续激活（避免大型语料因单次偶然匹配被误路由）；对话历史中的引用被确定性提取，用于回指跟踪问题。

**(d) 双层上下文与模型触发的逐字补全（Two-Tier Context / Hydration）— 第 6 节**
- **第一层（骨架）**：仅含确定性事实、图谱结构、坐标轴对齐——**零散文块**。
- **协议**：模型要么直接从骨架回答，要么发出**有界取指令**（每个命名 KB 清单中的文件）。
- 系统解析指令、对照 KB 清单验证、取回限定到命名文件的逐字跨度——"取，不发现"；全局向量填充仅作为饥饿阀门。
- **免训练**：是个 prompt 契约，任何聊天模型都能遵循；无控制 token、无 RL、无约束解码。
- **整体性保证**：解析失败/取失败/LLM 失败一律降级到先前变体的回答，不崩溃。

### 第 7 节：认知分层与地址约束装配（Epistemic Tiering）

- 上下文按**证据选择的机制（认知状态）** 而非单一相似度分数装配：
  - **第 0 层（计算）**：生产者计算的事实，逐字渲染。
  - **第 1 层（寻址）**：确定性寻址解析的逐字跨度，每个跨度携带源文件和解析的地址窗口；置于第 0 层之后、永不与排序块竞争注意力（缓解"middle lost"位置偏差）。
  - **第 2 层（发现）**：残余 token 预算下的语义填充（类似标准 RAG）。
- **双层装配（bilevel）**：确定性寻址解析出文件集 F 后，语义填充**约束在 F 内**；但此约束在有界取不足时通过"饥饿阀门"恢复全局填充，永远不限制覆盖率；无地址可解析时，装配恰好退化为无约束行为。

### 第 8.5 节：上下文预算削减

- **神经读出层可省略**：策略只作用于神经激活读出层；确定性层构造上不可被移除。
- **骨架按分数比例分配**：全球字符上限下，按路由分数比例分配图谱骨架（确定性舍入、行边界截断），替代按源顺序的均匀切割——防止高相关 KB 被饿死。

## 6. 主要结论与发现（F1–F13）

- **F1 固定基础设施下规模平价**：2B 模型在所有运行中精确保持值、诚实拒答、干净归因，与 35B 对齐。因为 2B 不可能记忆 35B 的参数知识，打平即证明答案来自确定性基础设施而非参数知识。
- **F2 陷阱零编造**：不存在的节目 4/4 诚实拒答，无数值被归因给它。
- **F3 证据验证**：一个水合臂运行中 35B 模型主动发出水合请求（带着"if it exists"的措辞）检查真实文件后才拒答。
- **F4 自发指令发射**：FULL 模式（无协议 token、top-k 未命中目标块）下两个模型自发发出取指令并命名正确文件，6/6 运行——提示触发行为可能是预训练模型的潜在能力。
- **F5 逐字细节的规模依赖精度**：35B 水合回答含精确时间戳；2B 逐字引用对话但省略时间戳。内容保真在 2B 保持，位置细节优雅降级。
- **F6 只有需要时才付水合成本**：定量问题停在第 1 阶段；叙述问题第 2 阶段仍比急切全语境快（~8s 对 ~29s）。
- **F7 寻址问题无需语义散文即可解析**：48 次运行零水合取；零跨节目泄漏；2B 与 35B 内容完全对齐（18/24 严格指标，6 个近失为格式问题——不回声节目名）。
- **F8 超越目标电池的一致性**：扩展电池 85/85 通过，冷生产栈 + 18 个活跃 KB。
- **F9 释义鲁棒性的特征化极限**：跨语言释义（英文改写意大利文件名）丢失 token 重叠→来源范围弱化→模型诚实报告缺失而非编造。极限在跨语言名称匹配，非生成错误。
- **F10 并发优雅降级**：4/8 并发全通过，延迟按争用比例退化。
- **F11 确定性层承载答案，神经读出层可省**：去掉读出层（多 KB prompt 的 42–50%），50/50 多 KB 运行全过且延迟中位数降 1/3。
- **F12 按分数比例分配骨架质量中性**：全局字符上限下按路由分数分配图谱骨架，保持质量、prompt 减 26%、TTFT 降 26%；均匀切割会系统性地扣留高相关 KB 的骨架。
- **F13 问题对齐的事实结构消除多实体误读**：扁平事实列表导致"上下文不含 [实体 A] 值"的错误拒答（尽管字节级验证值在场）；贪心解码并非比特确定（多线程量化推理近平局 token 决策有非确定性）；修复方式是在确定性层做结构变更（每实体连续块+并列双值行），此后 20/20 零失败。

## 7. 优点

1. **"确定性优先"的架构哲学极为清晰**：每一个能被基础设施确定性判断的步骤都不留给模型，生成前的所有判断已被做出——彻底逆转了"先让模型推理、后修正"的范式。
2. **循证设计（Failure-Driven）**：每个机制都源于实测的生产故障而非假设，观察→根因修复→重测直至保证成立。
3. **评估策略精心设计**：a) 模型交换方向刻意不利（35B 权重知识远多于 2B，2B 打平即证答案来源）；b) 手工审查所有回答，不依赖自动指标；c) 从头构建的负面控制（陷阱问题）直接测试幻觉倾向；d) 最终构建在贪心解码下重验证，排除采样波动。
4. **诚实与可追溯性**：每个报告值构造上可追溯到确切来源和位置——这一性质对监管领域至关重要。
5. **免训练的现实可部署性**：无 RL、无控制 token、无约束解码，任何聊天模型遵循 prompt 契约即可——显著降低了采用壁垒。
6. **对自身局限透明**：明确声明 N=5 的方向性证据、单域名限制、样例规模小；报告了自动化指标对生成结果的误判（S5-FULL"needle check 通过但手工重分类为非答案"）并做了修正。
7. **优雅降级而非崩溃的设计哲学**贯穿全局：水合失败降级到前一变体、地址不解析降级到无约束行为、并发是队列而非断路口、小模型失败模式是诚实拒答而非编造。

## 8. 不足与局限

1. **统计功效极弱**：主要电池 N=5，单因素消融臂 N=1–3；论文承认"方向性而非统计性"。无置信区间、无显著性检验。
2. **领域覆盖单一**：仅广播媒体语料，虽声称机制通用，但未在论文中验证医疗、金融、法律等其他关键事实领域。
3. **语料规模太小**：演示 KB 仅数个源文档（扩展电池 18 个 KB）；无法评估真实企业语料规模下（百万级文档）路由、预算分配、寻址的效率与准确性退化。
4. **RLHF/偏好对齐缺失**：论文可能只用了普通聊天模型（原文未明确指定基础模型），"2B 能打平 35B"的结论在 SFT+DPO 对齐过的小模型上可能不成立。
5. **评判标准存在偏差风险**：对比以"期望出现的事实被提及"为 needle 标准；"结构得分"（标题、表格、因果连接词）奖励的是答案风格而非事实性，论文承认这一点但仍纳入报告。
6. **横跨多 KB 路由的规模疑问**：神经网络激活读出层（占 prompt 41–51%）被证明可移除——如果可移除，为何该读出层在完整架构中仍然存在并消耗 token？
7. **可复现性不足（计算条件公开度低）**：未公开 GPU 型号、量化配置、推理框架、显存需求和软件栈。
8. **专利状态的影响**：论文附带专利申请（两个申请号），源码和训练/推理配置未公开，第三方复现困难。
9. **报告形式偏重演示性**：例如计时测量（35B 的 21.4s、29s 等）报告的是单次/几次的粗略推断，未给出模型加载时间如何从"总时间"中拆分等细节。
10. **自发指令行为（F4）的解释力有限**：论文正确承认无法判断是预训练行为还是自然格式的趋同——这一证据不足以支撑"无需训练的触发机制"的普适结论。
